LLM-driven agentic framework for MOOSE phase-field simulation

Falsify it before you interpret it.

AutoMOOSE converts a natural-language materials problem into an executed MOOSE simulation, screens the run for completion, and tests supported outputs against model-specific physical invariants. Six agents and a bounded recovery loop — with detection deliberately separated from correction.

S =  f₅∘ f₆∘ f₄∘ f₃∘ f₂∘ f₁ (U)

Composition reads right to left, so the run-time order is f₁ → f₂ → f₃ → f₄ → f₆ → f₅.
The Skeptic sits between screening and interpretation: no supported result is interpreted until the configured invariant tests have attempted to falsify it.

Architecture

Six agents, and a loop that closes

The pipeline is not a straight line. A falsified-but-recoverable run does not go to the user — it goes back to f₂ with a bounded, logged correction, and is re-admitted only if it re-completes and the Skeptic clears it the second time.

The Skeptic · f₆

Invariants are laws the result must obey if it is real

The Skeptic does not ask whether the simulation ran. It asks whether the result should be believed, and it tries to prove that it should not. Each test below is a falsification hypothesis. A run is credible only when every one of them fails to break it.

Grain growth Allen–Cahn · per run

  • T1monotonicity — grain count is non-increasing. A sustained rise means spontaneous nucleation, which is non-physical.flags any jump > +1, or a net rise above tracker noise
  • T2asymptotic — the initial grain count matches what was requested, and coarsening slows as N → 1.N(0) within 20 % of the requested N₀
  • T3parabolic scaling — Burke–Turnbull: 1/N is linear in t, with positive slope.R² ≥ 0.90, else the window is too short or the kinetics are anomalous
  • T5numerical integrity — no fatal solver breakdown, and the run advanced in time.an MPI abort, or no time advance at all — transient DIVERGED_ITS from adaptive dt is not failure
  • T4Arrhenius consistency — across a temperature sweep, k increases with T and ln k is linear in 1/T.cross-run · R² ≥ 0.90 · yields Q = −slope · kB

Spinodal Cahn–Hilliard · per run

  • S1mass conservation — ∫c dV is constant. This is an exact law, not a heuristic.relative drift tolerance 1 × 10⁻⁶ — numerical only
  • S2free-energy dissipation — total free energy is non-increasing. Exact, because Cahn–Hilliard is a gradient flow.any sustained rise falsifies the run outright
  • S3coarsening scaling — domain count decreases and L(t) follows a power law.Lifshitz–Slyozov, exponent approaching ≈ 1/3
Why the conserved domain is the stronger test. Grain-growth invariants are phenomenological — a bad run can still look plausible. Cahn–Hilliard's invariants are exact conservation laws, so a violation is not a matter of degree. There is nowhere for a broken run to hide.

Recovery · detection separated from correction

Detection is separated from correction

An adversary that can patch its own target stops being an adversary — so falsification and correction live in different modules. f₆ produces a verdict and a diagnosis; recovery.py decides what to do about it. Pick a failure class to see the correction it is permitted to make.

MAX_ATTEMPTS 3 MIN_DT0 1.0 ns MAX_REFINE 4 MAX_NX 96 MAX_END_TIME 16 000 ns
SOLVER_DIVERGENCEclassify_failure()

Every edit carries a {from, to, why} record, so a corrected run is fully auditable. Corrections touch only numerical and discretization controls — the time step, the mesh, the integration window. Physical parameters (T, Q, GBmob0, GBenergy, c0) are never edited. A corrected run is accepted only if it re-completes and the Skeptic re-admits it. If the attempt cap is exhausted, the task is flagged as outside the validated envelope rather than silently reported.

New physics without touching an agent

    "params":         {...},           # name -> {default, range, ...}
    "sweepable":      ["T", ...],       # what a sweep may vary
    "executable_key": "MOOSE_EXEC",   # env var: solver path
}

def generate_input(**params) -> str:
    """Return a complete MOOSE .i input file as a string."""

def parse_results(csv_data) -> dict:      # optional
    """Map MOOSE postprocessor CSV output to a metrics dict."""

      

      

        Honest about its own limits
        

          A stub is not a silent failure. Ask AutoMOOSE for a dendritic solidification run today and it will not improvise one. The registry knows solidification is a template, and the backend refuses the request with an HTTP 400 before a single agent is invoked. The system's advertised capability and its actual capability are the same object.
        

        

          Model-agnostic by configuration. Claude, Qwen, or a self-hosted open-weights model behind an OpenAI-compatible endpoint. Provider, model, and endpoint are read from config.env — a configuration change, not a code change.

Raw direct authoring is fragile even for strong models — validity swings between attempts of the same model. AutoMOOSE routes the LLM’s reasoning into parameterization and screening, and leaves deck syntax to deterministic plugin code, which is why its input validity is not a matter of sampling luck. Figures are from the repository’s committed ablation records; model identities are in the JSON.
